# 動作確認テスト

ブラウザ（Playwright）でゲームを実際に動かして、エラーが出ないか・画面がくずれていないかを確かめる。
スクリーンショットは `tools/tests/shots/` にたまる（git には入らない）。

## はじめての時だけ
```
cd tools/tests
npm install
npx playwright install chromium
```

## 実行
リポジトリのいちばん上で
```
sh tools/test.sh              # ぜんぶ
sh tools/test.sh sewa layout  # 名前を指定
```
`tools/test.sh` がローカルサーバー（ポート 8765）を立てて、終わったら止める。

## テストの中身
| ファイル | 確かめること |
|---|---|
| sewa | ゆび・きりふき・ふきんなどのお世話、かくれ家をのぞく |
| kirifuki | きりふきのかけ方（一か所・虫にかける・ぜんたい）としめりけ |
| yurasu | ケースをゆらしたときの虫の反応（小さく／大きく） |
| kazari | お店でかざりを買う、置く・動かす・しまう、マット |
| tsukamaeru_dappi | 虫をつかまえる、カード、脱皮、ずかん |
| taisen | 対戦（わざ・せいかく・はやおくり） |
| mushikago_kau | 虫かごを買う・入れかえる、つかまえた虫の入れ先をえらぶ |
| tate_yoko | たて持ち（回転）と横持ちで、タップ位置がずれないか |
| layout | 画面の大きさ・ノッチありなしで、はみ出し・スクロールが出ないか |
| panel_haba | 右メニューのパネルの幅・位置、ケースの虫が切れないか |

うまく動かない時は、エラーの内容を Claude に見せてね。
