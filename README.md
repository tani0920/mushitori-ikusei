# むなかた 虫そだて日記〈1週間〉

宗像の森や川、町で見つけた虫を、おうちの虫かごでそだてて、もとの場所にかえすゲームです。
本物なら何か月もかかる虫の飼育を、ゲームの中では1週間ほどにちぢめています。幼虫が脱皮して、さなぎになり、羽化するまでを見守りながら、命の大切さや、飼い方のこつ・むずかしいところを、おうちの人といっしょに体験できます。
「[むなかた虫とり日記](https://github.com/tani0920/mushitori-rpg)」の姉妹作です。

**遊ぶ：** https://tani0920.github.io/mushitori-ikusei/

iPhone・iPad は Safari で開いて「共有 → ホーム画面に追加」すると、アプリのように全画面で遊べます。横向きの画面で遊ぶゲームです。

## どんなゲーム？

- **そと**：宗像大社・城山・さつき松原・釣川・赤間・大島などに、おうちの人といっしょに出かけて、虫をさがします。
- **虫かご**：観察ノートを見ながら、エサやきりふき、そうじで虫の世話をします。虫めがねでのぞいたり、そっとさわったりできます。
- **おみせ**：どんぐりで、虫かご・エサ・土・かざりを買えます。
- **すもう**：育てた成虫で、近所の子どもたちと虫ずもうをします。
- **ずかん**：見つけた虫と、そだてた虫が記録されます。

## 知っておいてほしいこと

- ゲームに出てくる場所と虫の組み合わせはゲーム用のもので、実際にその場所にいる虫とはかぎりません。
- ゲームの中で虫がそだつ速さは、本物よりずっと速くしています（ずかんに「じっさいは」を書いています）。
- 「ミアレカブト」は、このゲームのための架空の昆虫です（宗像大社のみあれ祭にちなんだ名前）。
- 外に出るときは、おうちの人といっしょに。虫には、やさしくさわってね。
- セーブはこの端末の中だけに保存します。位置情報は、近くの場所を調べるときだけ使って、すぐに捨てます。
