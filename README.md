# むなかた虫そだて（仮称）

宗像市内の実在スポットを親子で歩いて虫をみつけ、おうちの飼育ケースで「そだてて、かえす」位置情報ゲーム。
「[むなかた虫とり日記](https://github.com/tani0920/mushitori-rpg)」の兄弟作で、同じルールと見た目で作っている。

**遊ぶ（デモ）：** https://tani0920.github.io/mushitori-ikusei/

iPhone・iPadは Safari で開いて「共有 → ホーム画面に追加」すると、アプリのように全画面で遊べる。

- 企画の内容は [企画メモ.md](./企画メモ.md) を参照。
- ゲームに出てくる場所と虫の組み合わせはゲーム用のもので、実際にその場所にいる虫とはかぎらない。
- ゲームの中で虫がそだつ速さは、本物よりずっと速い（標準1〜2週間）。ずかんに「じっさいは」を書いてある。

## 構成

| ファイル | 役わり |
|---|---|
| `index.html` | ゲーム本体（1ファイル。CSS・JS・虫のSVGをすべて含む） |
| `manifest.webmanifest` | ホーム画面に追加するための設定 |
| `version.json` | 公開番号。本体の `BUILD` と比べて「新しいバージョンがあります」を出す |
| `img/icons/` | アプリのアイコン |
| `tools/bump.sh` | 公開するときに公開番号を書きこむ |

## 「虫とり日記」から引き継いでいるルール

- **アップのルール**：公開するたびに `sh tools/bump.sh` を実行して `BUILD` と `version.json` を更新する。`GAME_VER` と `CHANGELOG` は `index.html` の中で手で上げる（ふだんは +0.0.1、大きな更新は +0.1）。アプリは起動時と、ほかのアプリから戻ったときに `version.json` を見て、新しければ「こうしんする」バーを出す。更新前に「セーブをわすれずに」を出す。
- **デモ版**：`/demo/` の下で開くとデモ版扱い（セーブのキーを分ける・noindex・「デモ版」バッジ）。`?demo=1` を付けて開くと本物のセーブを上書きしない。
- **じどうセーブ**：お世話をするたびに保存。ほかのアプリに切りかえたとき（visibilitychange / pagehide）にも保存。オプションでON/OFF。
- **漢字とふりがな**：本文は小学生向けの漢字で書き、小学5年生以上の漢字と難しい地名には自動でふりがなを付ける。「ふりがな：たくさん」で小3以上にも付く。辞書は `RUBY`（読み|学年）。ふりがなを付けたくない要素には `norb` クラス。設定のキー名は虫とり日記と同じなので、どちらかで切りかえると両方にきく。
- **操作**：画面下のタブ、「とじる」はいつも右下、Esc／X でもどる。
- **安全と位置情報**：そとへ出る前に1日1回「おうちの人といっしょ？」を聞く。位置は「スポットの半径内か」を判定したらすぐ捨てる。どんぐり（移動距離のごほうび）はスポット同士の距離から計算し、本人の位置は保存しない。画面確認用に `?geo=緯度,経度`。
- **そだてのやくそく**：はじめての場面でひとことずつ教える（エサ・きりふき・そうじ・脱皮・さなぎ・羽化・かえす・見るだけ）。

## 動作の確認

ブラウザで `index.html` を開くだけで遊べる（ローカルでは `python3 -m http.server` などで配信すると `version.json` の確認も動く）。
オプションの「デモ用」に、時間を進めるボタンと場所に着いたことにするボタンがある（本番にはない）。
